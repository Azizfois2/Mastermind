01 — Le jeu

Simple à comprendre.
Tendu à résoudre.

Pas de compte, pas de connexion, pas de publicité. Deux personnes, un clavier, et un code que l'un connaît et que l'autre doit retrouver.

Deux modes

Débutant impose cinq chiffres distincts. Expert autorise les répétitions, dans le code comme dans les essais.

Indices précis

Chaque essai indique les chiffres bien placés et mal placés. Un chiffre du code n'est compté qu'une seule fois.

Deux jokers

Révéler un chiffre ou identifier un chiffre absent : deux coups de pouce qui se paient en tentatives.

Score XP

Cent points par tentative restante, deux mille au maximum. Les meilleurs scores sont conservés par pseudo.

Natif Windows

Écrit en C avec l'API Win32. Une fenêtre, des dialogues, une icône : aucune dépendance, aucun runtime.

Hors-ligne

Un exécutable d'environ un mégaoctet. Il démarre instantanément et fonctionne sans réseau ni installation.

02 — Règles

Une partie, quatre temps.

Tout se joue en alternance sur le même poste. Le joueur 1 ne voit plus le code après validation ; le joueur 2 doit faire parler les indices.

  1. 01

    Le joueur 1 compose le code

    Cinq chiffres de 0 à 9, saisis à l'aveugle ou tirés avec le bouton Code aléatoire. Le mode choisi détermine si les chiffres peuvent se répéter.

  2. 02

    Le joueur 2 propose un essai

    Il dispose de vingt tentatives. Chaque essai doit contenir exactement cinq chiffres ; en mode Débutant, tous distincts.

  3. 03

    Les indices guident la déduction

    « Bien placés » signale un bon chiffre à la bonne position. « Mal placés » signale un bon chiffre à la mauvaise position. Le reste est absent du code.

  4. 04

    Le score récompense la vitesse

    Trouver le code rapporte cent points par tentative restante. Abandonner ou épuiser les vingt essais termine la partie sans score.

Démo · mode débutant 20 essais

Aucun essai pour l'instant.

03 — Jokers

Deux coups de pouce.
Un seul par partie.

Les jokers n'apparaissent qu'à partir de dix tentatives restantes. Leur coût est prélevé immédiatement — et réduit d'autant le score final.

Joker 1 — Révéler une position

Un chiffre du code, à l'endroit exact

−3 essais

Saisissez un seul chiffre de 0 à 4 dans le champ, puis cliquez sur Joker 1. Il sert d'index : 0 pour la première position, 4 pour la cinquième.

  • Disponible seulement s'il reste plus de 3 tentatives.
  • Ne consomme pas d'essai supplémentaire : le coût est déduit directement.
  • Un essai complet de cinq chiffres est refusé.

Joker 2 — Éliminer un chiffre

Un chiffre absent du code secret

−5 essais

Aucune saisie : le jeu parcourt les chiffres de 1 à 9 et vous en montre un qui ne figure pas dans le code. Une certitude utile pour resserrer les possibilités.

  • Disponible seulement s'il reste plus de 5 tentatives.
  • Ne proposera jamais 0, même s'il est absent du code.
  • Comme le Joker 1, il ferme définitivement les deux boutons.

À retenir : les deux boutons restent cachés tant que le compteur est supérieur à 10, et disparaissent dès qu'un joker est utilisé. À 3 tentatives restantes ou moins, plus aucun joker n'est proposé.

04 — Score

Chaque essai économisé compte.

Le barème ne dépend que des tentatives restantes au moment de la victoire. L'essai gagnant est offert : trouver le code du premier coup rapporte le maximum.

Formule

score = tentatives restantes × 100 XP

Deux mille points au maximum. Avec un pseudo, le score est ajouté au cumul du joueur et la partie est archivée dans deux fichiers texte locaux.
